1. Pendahuluan & Latar Belakang

Undangan digital berbasis website saat ini merupakan media interaksi utama dalam pernikahan dan acara formal. Namun, kendala umum yang sering terjadi di industri mencakup tampilan yang melebar tak beraturan saat dibuka di layar laptop/PC, tombol navigasi bawah yang kaku dan menutupi konten, serta kesulitan dalam mempersonalisasi nama tamu secara otomatis.

Dokumen ini menyusun standarisasi arsitektur dan pengalaman pengguna (UX) untuk pembuatan template undangan digital berbasis ReactJS, memastikan konsistensi visual di berbagai resolusi layar, navigasi yang intuitif, serta arsitektur data modular.

Tujuan Produk (Core Objectives)

  • Standar Tampilan Mobile-First: Layout otomatis terkunci dalam rasio mobile screen dan berada tepat di tengah layar ketika dibuka di laptop/PC.
  • Floating Pill Bottom Navbar: Navigasi bawah berbentuk melayang (*floating*), tidak *full-width*, berujung melengkung penuh (*full rounded*), dan mendukung interaksi satu tangan.
  • Personalisasi Tamu via URL: Otomasi pembacaan nama tamu dari parameter URL (contoh: /wedding-invitation?name=Putra) dengan sanitasi data dan *fallback* aman.
  • 9 Seksi Halaman Terstandarisasi: Struktur alur konten seragam mulai dari *Opening, Couple, Quotes, Event, Countdown, Galeri, RSVP, Gift,* hingga *Thanks*.
  • Data-Driven Architecture: Seluruh teks, tanggal, foto, jadwal acara, dan nomor rekening dipisahkan ke dalam satu file konfigurasi JSON.

2. Standarisasi Layout & User Experience (UX/UI)

2.1 Viewport Container (Strict 100vh - Zero Scroll Layout)

  • Ketinggian Terkunci Maksimal 100vh / 100dvh: Container dan setiap seksi tidak dapat di-scroll (overflow-hidden), memastikan seluruh informasi pas di layar tanpa terpotong atau tertutup.
  • Mobile Devices (< 480px): Tampilan memenuhi layar 100% lebar dan 100dvh tinggi.
  • Desktop / Laptop / Tablet (> 480px):
    • Container konten terkunci pada lebar smartphone modern: max-w-[440px] dan tinggi tepat 100dvh.
    • Container diposisikan tepat di tengah layar secara horizontal (mx-auto).
    • Area luar container diisi dengan backdrop gelap dan ambient glow estetik.

2.2 Bottom Floating Navbar (4 Menu Tampil & Horizontal Scrollable)

  • Posisi: Melayang di bagian bawah layar (bottom-3) di dalam batas mobile container.
  • Kapasitas Tampilan: Menampilkan tepat 4 menu ikon sekaligus secara proporsional (tidak berdesakan).
  • Scroll Horizontal: Dapat digulirkan ke kanan dan ke kiri secara halus (overflow-x-auto snap-x), dilengkapi tombol panah navigasi di kedua sisi.
  • Pill Shaped: Berbentuk kapsul rounded penuh dengan efek kaca glassmorphism (backdrop-blur-xl) dan border gold tipis.
  • Auto Scroll Active Tab: Tab yang sedang aktif otomatis berpindah ke tengah viewport navbar.

2.3 Kontrol Pemutar Audio & Musik

Aturan Autoplay Browser Modern
Browser modern (Chrome, Safari, Edge) memblokir audio autoplay sebelum adanya interaksi pengguna. Audio otomatis diputar setelah tamu menekan tombol "Buka Undangan" di seksi Opening.
  • Tombol melayang (*floating action button*) pemutar musik disediakan di sudut atas/bawah untuk memutar atau menjeda musik sewaktu-waktu.
  • Tampilan visual ikon berputar secara halus saat musik sedang dimainkan (*spinning vinyl effect*).

3. Spesifikasi Parameter URL & Personalisasi Tamu

Untuk memudahkan distribusi undangan via WhatsApp/Instagram/Email, nama tamu disematkan langsung di dalam URL query parameter.

Komponen Format / Contoh Keterangan
Primary Parameter ?name=Putra Parameter utama yang diekstrak oleh aplikasi.
Dukungan Spasi / Simbol ?name=Putra%20Wira atau ?name=Putra+Wira Aplikasi melakukan decodeURIComponent() otomatis.
Parameter Alias ?to=Putra atau ?guest=Putra Sistem mendukung alias jika pembuat tautan memakai variasi parameter.
Fallback Default Teks: "Tamu Undangan" Ditampilkan jika URL diakses langsung tanpa query parameter.
Sanitasi Keamanan Pembersihan tag HTML / Karakter Berbahaya Mencegah kerentanan Cross-Site Scripting (XSS).

4. Standarisasi Struktur Halaman (9 Seksi Inti)

ALUR KONTEN TEMPLATE UNDANGAN: [01. Opening Cover] ──(Buka Undangan)──> [Unlock Scroll & Play Music] ↓ [02. Couple] ──> [03. Quotes] ──> [04. Event & Maps] ──> [05. Countdown] ↓ [06. Galeri] ──> [07. RSVP & Ucapan] ──> [08. Gift / Titip Kado] ──> [09. Thanks]
Seksi Komponen & Konten Wajib Aksi & Interaktivitas Pengguna
1. Opening (Cover) Judul pernikahan, nama mempelai, tanggal utama, label "Kepada Yth. Bapak/Ibu/Saudara/i:", dan nama tamu dinamis. Tombol "Buka Undangan" untuk membuka lock scroll, memutar background audio, dan menampilkan floating navbar.
2. Couple (Mempelai) Salam pembuka, doa syukur, profil mempelai pria (foto, nama lengkap, gelar, orang tua, IG) dan profil mempelai wanita. Link profil Instagram mempelai (opsional), transisi animasi fade-in saat di-scroll.
3. Quotes (Ayat/Doa) Kutipan ayat suci pernikahan (QS. Ar-Rum: 21 / ayat Alkitab) atau kata mutiara romantis beserta terjemahannya. Tipografi estetik dengan aksen ornamen pemisah.
4. Event (Acara) Jadwal terpisah untuk Akad Nikah / Pemberkatan dan Resepsi (hari, tanggal, jam, nama gedung, alamat lengkap). Tombol "Buka Google Maps", embed peta interaktif, dan tombol "Simpan ke Kalender" (Google Calendar / iCal).
5. Countdown Komponen hitung mundur real-time: Hari, Jam, Menit, dan Detik menuju tanggal acara utama. Pembaruan otomatis per detik; status berganti jadi "Acara Sedang Berlangsung" jika waktu tiba.
6. Galeri Grid / Masonry susunan foto prewedding dan pemutar video teaser (embed YouTube/Vimeo/MP4). Fitur Lightbox Modal (klik foto untuk melihat ukuran penuh dengan navigasi next/previous).
7. RSVP & Ucapan Formulir konfirmasi kehadiran (Nama, Jumlah Kehadiran, Status Hadir/Tidak, Pesan Doa) dan daftar doa tamu. Kirim formulir interaktif; daftar ucapan tertampil realtime layaknya buku tamu digital.
8. Gift (Amplop Digital) Informasi Rekening Bank, QRIS digital, serta alamat tujuan untuk pengiriman kado fisik. Tombol "Salin Nomor Rekening" & "Salin Alamat" dengan feedback toast notification.
9. Thanks (Penutup) Ucapan terima kasih keluarga besar, foto penutup/siluet, serta footer copyright platform undangan. Tombol kembali ke atas (*Back to Top*) atau link sosial media resmi.

5. Arsitektur Teknis & Struktur Data (ReactJS)

5.1 Tech Stack Standar

  • Core Framework: ReactJS (dibuat menggunakan Vite untuk performa build cepat dan ringan).
  • CSS Framework: Tailwind CSS (utility-first, responsive utilities, arbitrary values).
  • Iconography: Lucide React (ikon modern, clean, dan konsisten).
  • Animation Engine: Framer Motion (transisi halus saat buka undangan, reveal saat scroll, lightbox).
  • Data Pattern: Single Source of Truth menggunakan invitationData.json.

6. Kebutuhan Non-Fungsional & Kualitas Produk

  • Optimasi Performa Web: Semua aset gambar dikompresi ke format WebP atau AVIF dan menerapkan *lazy loading* untuk menjamin waktu muat layar pertama di bawah 1.5 detik pada koneksi seluler.
  • Aksesibilitas & Standar Warna: Rasio kontras teks terhadap latar belakang minimal 4.5:1 (memenuhi standar WCAG AA).
  • Cross-Platform Compatibility: Berfungsi sempurna di browser mobile (Safari iOS, Chrome Android) dan browser desktop (Chrome, Edge, Firefox, Safari macOS).
  • User Feedback: Salin nomor rekening memberikan umpan balik visual instan berupa toast *"Nomor rekening berhasil disalin!"*.
