# Panduan Aset Gambar Ornamen Undangan Digital

Direktori ini digunakan untuk menyimpan gambar ornamen dekoratif di sudut/samping layar undangan digital.

---

## 📐 Rekomendasi Ukuran & Format Gambar

| Posisi Ornamen | Nama File Default | Rekomendasi Dimensi (1x / 2x Retina) | Format Gambar | Keterangan |
| :--- | :--- | :--- | :--- | :--- |
| **Pojok Kiri Atas** | `ornament-top-left.png` (atau `.svg` / `.webp`) | **150 × 150 px** *(atau 300 × 300 px @2x)* | PNG Transparan / SVG | Bunga/daun menghadap ke arah tengah bawah |
| **Pojok Kanan Atas** | `ornament-top-right.png` (atau `.svg` / `.webp`) | **150 × 150 px** *(atau 300 × 300 px @2x)* | PNG Transparan / SVG | Bunga/daun menghadap ke arah tengah bawah |
| **Pojok Kiri Bawah** | `ornament-bottom-left.png` (atau `.svg` / `.webp`) | **140 × 140 px** *(atau 280 × 280 px @2x)* | PNG Transparan / SVG | Bunga/daun menghadap ke arah tengah atas |
| **Pojok Kanan Bawah** | `ornament-bottom-right.png` (atau `.svg` / `.webp`) | **140 × 140 px** *(atau 280 × 280 px @2x)* | PNG Transparan / SVG | Bunga/daun menghadap ke arah tengah atas |
| **Sisi Kiri / Kanan** *(Opsional)* | `ornament-side.png` | **60 × 200 px** *(atau 120 × 400 px @2x)* | PNG Transparan / SVG | Daun/ranting memanjang vertikal |

---

## 💡 Tips Pembuatan Gambar:
1. **Gunakan Background Transparan**: Simpan file dalam format **PNG 32-bit**, **WebP**, atau **SVG vektor** agar latar belakang transparan menyatu dengan warna undangan.
2. **Kompresi Gambar**: Pastikan ukuran file kecil (< 80 KB per gambar) agar website tetap cepat dibuka di jaringan seluler (bisa menggunakan TinyPNG).
3. **Resolusi Retina**: Disarankan mendesain pada ukuran **300 × 300 px** agar terlihat tajam dan tidak pecah pada layar smartphone modern (iPhone Retina, Samsung AMOLED, dll.).
4. **Warna & Tema**: Sesuaikan warna ilustrasi dengan tema undangan (misal: warna emas *champagne*, hijau *sage*, atau *soft floral*).
